Help & Support

Countlane

Start counting

Create and name a set, then add related counters inside it. Tap a number to increase it or use minus to decrease it. Each counter has its own starting value, step, and optional target.

Check and export

Open a counter’s menu to inspect time-stamped history, set its current value, undo, or reset. Reset returns a counter to its starting value and keeps history; resetting a set resets each counter separately. Export all history for the set as CSV at the bottom of the set, then choose a location in the system file exporter. History and export are also included in the free version. Keep exported files yourself.

Purchases and restoration

Pro is an optional one-time purchase, not a subscription. To restore, use the original purchasing Apple Account and choose Restore Purchases in the app. A purchase being unavailable does not delete existing records. For billing or refunds, use Apple’s purchase history and official refund channels.

Data and backup

The app has no accounts or cloud sync. Export any history you need before uninstalling or changing devices. CSV is a record export; it is not a promise of app-state import or recovery.

Contact support

Email guan.yeshu@gmail.com with the app version, iOS/iPadOS version, steps to reproduce, and any error message. Do not send Apple Account passwords, payment details, or unnecessary private counter content.
