一笔小人

使用帮助与支持

开始创作

在「灵感画室」选一个小人，或者点击「创作」。用动作、表情、配件、动画、文字和画布工具调整作品。点击「保存」后可在「我的作品」继续编辑。

制作聊天表情包

中文模式：我的作品 → 制作微信表情包 → 从作品或内置素材选图 → 导出素材。选择 PNG / GIF 格式，按需附带表情封面和面板图标，再保存到相册。在微信的选图或添加表情界面自行选择文件。

英文模式：My Drawings → Make WhatsApp Stickers → 选择 3–30 张作品 → Export。选择 Static 或 Animated，通过 Add to WhatsApp 到 WhatsApp 预览确认，或通过文件分享保存。每包使用一种格式；主图为 512 × 512 WebP，包图标为 96 × 96 PNG。没有安装 WhatsApp 时仍可分享原文件。

导出和相册权限

单张作品也可通过编辑器右上角导出图标分享或保存到文件。如相册保存失败，请检查 iOS 设置中的“添加照片”权限和设备剩余空间，再重试。

语言与版本

支持简体中文、繁体中文、英文、日语、韩语、西班牙语、法语、德语和葡萄牙语（巴西），默认跟随系统。可在「我的作品 → 关于 → 语言」中手动切换，下次启动仍会保留选择。切换语言不会改写已保存的作品标题和配文。「关于」还提供版本、功能介绍及「隐私与用户协议」。意见反馈会跳转 App Store；首次发布前商店页面可能暂不可用。

备份与反馈

作品保存在设备内，请在卸载前导出。没有账号或云端恢复服务。常规评价可通过 App 内「关于 → 意见反馈」前往 App Store；技术问题也可发邮件至 guan.yeshu@gmail.com，并附 App 版本、iOS 版本和重现步骤。
