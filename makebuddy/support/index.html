开始使用

无需注册巧伴账户。点击「先体验一个示例」，选择轻待办或心情日记，即可体验本机记录功能。

需要创建新应用或通过 AI 修改时，在「设置」中填写自己的 DeepSeek API Key，并测试连接。消息及相关应用文件会发送给 DeepSeek；请先阅读隐私政策与用户协议，避免发送不必要的敏感资料。

保存与恢复

小应用中的记录保存在本机。在应用菜单中可导出备份，在设置中可导入备份。移除的应用可从「设置 → 最近删除」恢复。当前没有云同步，卸载前请导出重要资料。

连接与能力限制

连接失败时请检查网络、密钥有效性及 DeepSeek 账户余额。巧伴不能代你恢复 DeepSeek 密钥或管理其账单。AI 创建前会评估需求，某些系统能力或外部网络功能可能无法实现。

联系支持与报告问题

使用问题、不合适的生成内容或隐私请求，可联系 guan.yeshu@gmail.com。请提供设备型号、系统版本、巧伴版本、操作步骤和已遮去私人信息的截图。不要发送 API Key 或完整私人记录。

Getting started

No MakeBuddy account is required. Tap 先体验一个示例 (Try an example) and choose the to-do or mood journal example to try local records. The current interface is Simplified Chinese.

For AI creation and changes, add your own DeepSeek API key in Settings and test the connection. Messages and relevant app files are sent to DeepSeek. Read the Privacy Policy and Terms and avoid unnecessary sensitive data.

Saving and restoring

Records stay on the device. Export a backup from the app menu and import one in Settings. Restore removed apps from Settings → Recently Deleted. Cloud sync is not included; back up important data before uninstalling.

Connection and capability limits

Check your network, API key validity, and DeepSeek account balance if a connection fails. MakeBuddy cannot recover your DeepSeek keys or manage its bills. Requests are assessed before creation; some system capabilities and external networking features are unavailable.

Support and reports

For help, inappropriate generated content, or privacy requests, contact guan.yeshu@gmail.com. Include device model, OS and app versions, steps, and a redacted screenshot. Never send API keys or complete private records.
