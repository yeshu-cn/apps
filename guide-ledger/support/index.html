使用帮助

如何保存备份？

在“我的 → 数据管理”中导出 JSON 备份，再通过系统分享面板保存到文件应用等位置。更换设备、卸载或导入前，请先备份当前数据。

导入会覆盖现有数据吗？

会。导入备份会覆盖当前账本，请核对文件，并先另外保存一份现有账本。

如何导出报账 PDF？

在行程的报账页面选择导出，通过系统分享面板保存或发送。若某个接收应用无法保存，可尝试系统文件应用。

总收入包含签单吗？

包含。总收入、收入趋势和旅行社排行合并计算现金与签单收入。

换设备后如何恢复？

从旧设备导出 JSON 备份并传到新设备，在新设备的数据管理页面导入。当前版本没有账号或自动云同步。

删除 App 前要做什么？

先导出备份，确认文件已保存在 App 之外。卸载后，本地账本可能无法恢复；已经导出的文件需要在保存位置单独删除。
