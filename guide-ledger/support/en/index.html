How do I back up my ledger?

Open Profile → Backup & restore, export a JSON file and save it through the system share sheet. Back up before changing devices, uninstalling or importing data.

Will importing replace my records?

Yes. Importing a backup replaces the current ledger. Check the selected file and export a separate copy of your current ledger first.

How do I export a PDF report?

Open a trip’s expense report and choose Export PDF. Use the system share sheet to save or send it. If a destination app cannot save the file, try the system Files app.

Does total income include signed amounts?

Yes. Total income, the income chart and agency rankings include both cash and signed income.

How do I move to another device?

Export a JSON backup from the old device, transfer it to the new device, then import it in Backup & restore. The current version has no account or automatic cloud sync.

What should I do before uninstalling?

Export a backup and check that it is saved outside the app. Local records may not be recoverable after uninstalling. Delete exported copies separately if you no longer need them.

Currency

Amounts are recorded and displayed in Chinese yuan (CNY). Changing the interface language does not convert currencies or alter existing records.
