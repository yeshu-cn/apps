How to add dimensions to a photo on iPhone

A note that says “42 cm” loses its meaning surprisingly quickly. A dimension line on a photo shows both the number and the edge it belongs to. Here is a simple way to make that record useful to someone else.

Start with the whole object

Include all the edges you want to record, with a little space around them. Choose a surface whose corners are visible. If a handle or another object covers an endpoint, change your viewpoint before taking the photo.

Capture, then add a dimension

In SnapDim, take a new photo on a LiDAR-capable iPhone. Select an object to detect its boundary, or add a two-point dimension. Each measured line needs usable depth data and endpoints on the same surface. A line crossing from the front of a box to the wall behind it is not a measurement of either surface.

Make the line easy to read

Check that each endpoint touches the intended edge. Zoom in and refine annotations where needed. Add one useful dimension at a time, rather than covering every edge at once. Choose millimeters, centimeters, inches or decimal feet consistently.

Send the annotated image

Save the record so you can return to it. Share the annotated image when the recipient only needs to see the dimensions. In the message accompanying the image, name the object, say which side is shown and distinguish an overall size from a usable opening.

Can I measure a photo already in my camera roll?

This version of SnapDim starts with a new in-app capture and its depth data. It does not import an existing photo for calibration. If you only have an old photo, use a tool that supports manual dimension entry or a known-length reference; a visible dimension label alone does not prove that a length was measured.
